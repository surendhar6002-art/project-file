Week 5 - Spring AOP Employee Application

Requirements:
- JDK 17 or compatible
- Maven

Run:
1. Extract the ZIP file.
2. Open the SpringAOPEmployee folder in VS Code or a terminal.
3. Run: mvn clean compile
4. Run Main.java from VS Code.

Expected output:
Logging: Adding employee
Employee added: Sathya
Logging: Displaying employee
Employee ID: 101
Employee Name: Sathya
Logging: Calculating salary
Employee Salary: 25000.0

Required Java files are under:
src/main/java/com/example/employee/
